Curve Fitting
=============

For a full step-by-step flow, see :ref:`GUI Walkthrough — Curve Fitting and Fit Labels <gui-curve-fitting-and-fit-labels>`.

Available fits
--------------

PhysPlot supports 11 optional fit models:

1. Linear
2. Quadratic
3. Cubic
4. 4th degree
5. 5th degree
6. 6th degree
7. 7th degree
8. 8th degree
9. 9th degree
10. 10th degree
11. ``Ae^(-bx)`` (implemented as exponential ``a*exp(bx)`` fit)

Enable and label fits
---------------------

For each fit, you can:

- Enable/disable with checkbox
- Choose label mode:
  - Off
  - Equation
  - Custom Label
