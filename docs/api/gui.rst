GUI API (physplot_gui)
======================

The desktop application is the ``physplot_gui`` package. It only orchestrates: every
scientific operation is delegated to the ``physplot`` backend, and every user action is
recorded as a replayable workflow step. Each module's documentation starts with a
description of the part of the window it implements; the user-facing version of the
same material is the :doc:`../ui/index`.
