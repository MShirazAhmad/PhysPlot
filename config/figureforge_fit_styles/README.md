# Fit-style presets

LSQ fit-style presets (JSON) for Simple Mode's **Fit Style** menu. Choosing one
fills the **Fit Line** fields. Fields: `name`, `line_style` (`"--"`, `"-"`,
`"-."` or `":"`), `line_width`, `label` and `show_legend`; a preset has no
colour. Put your own in `Documents/PhysPlot/config/figureforge_fit_styles/` and
click the **Reload** button next to **Fit Style**. The Figure Editor's **Add Fit
Function** does not use these presets.

To have an AI assistant write a preset, attach `AI_GUIDE.md` from this folder to
the chat.
