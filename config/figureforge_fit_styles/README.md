# Figure Editor fit-style presets

LSQ fit-style presets (JSON) for Simple Mode and the Figure Editor. Fields:
`name`, `line_style`, `line_width`, `label`, `show_legend`. Presets saved from
the application land in `Documents/PhysPlot/config/figureforge_fit_styles/`
and are reloaded with the **Reload** button next to **Fit Style**.
