# Fit Functions

Legacy curve-fit models. Each file defines `DISPLAY_NAME`, `DEFAULT_LABEL`,
and `KIND` (`"poly"` with `DEGREE`, or `"callable"` with `function(x, ...)`).
Simple Mode's LSQ fit accepts a free-form expression instead and does not need
these files.

To have an AI assistant turn a model into LSQ fit entries (and a file for this
folder), attach `AI_GUIDE.md` from this folder to the chat.
