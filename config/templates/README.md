# Templates

Figure templates (JSON) applied after a plot is generated. Save new ones from
the Figure Editor with *PhysPlot > Save as Template*; they land in
`Documents/PhysPlot/config/templates/` and appear in the Simple Mode
**Template** menu after **Reload**.

To have an AI assistant write or adjust a template, attach `AI_GUIDE.md` from this
folder and a template you saved from the Figure Editor to the chat.
