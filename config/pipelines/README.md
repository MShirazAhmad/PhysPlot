# Pipelines

Reusable transformation pipeline JSON files: a list of column transformations
(`input`, `function`, `params`, `output`). PhysPlot 1.0 has no menu item for
them; apply one with the short script in `AI_GUIDE.md`, which also saves it as
a sequence. For transformations you want in the menus, use a protocol module
(`config/protocol_modules/`) instead.

To have an AI assistant write a pipeline, attach `AI_GUIDE.md` from this folder
to the chat.
