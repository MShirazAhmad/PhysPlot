# Sequences

Save reusable PhysPlot protocol sequence files here. These are normal Python
workflow files that define `WORKFLOW_STEPS` or `build_workflow()`.

Use `config/protocol_modules/` for smaller reusable protocol building blocks
or metadata, and `config/sequences/` for complete runnable sequences.

To have an AI assistant write or change a sequence, attach `AI_GUIDE.md` from
this folder, preferably with a `Sequence.py` exported from PhysPlot.
